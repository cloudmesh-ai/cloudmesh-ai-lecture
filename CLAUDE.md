# Project Guidelines - CloudMesh AI Lecture

## File System Rules
- **No Root Clutter**: Never create new files, temporary scripts, logs, or artifacts in the project root directory.
- **Helper Scripts**: All scripts, automation tools, or temporary Python files created to assist with tasks must be placed in the `claude-scripts/` directory.
- **Docs Placement**: All new documentation must be placed in the appropriate `docs/` subdirectory.
- **Naming Conventions**: Follow the existing project naming patterns (e.g., `name-chapter.md` or `name-tutorial.md`).
- **Cleanup**: Whenever possible, delete temporary helper scripts after the task they were created for is completed.
