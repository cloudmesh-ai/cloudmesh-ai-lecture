# Recording Audio with Autoplay

!!! info "Learning Objectives"
    - Understand how to record audio for PowerPoint presentations.
    - Learn to configure presentations for autoplay with synchronized sound.
    - Create a consecutive audio recording across multiple slides.

## Overview

PowerPoint provides mechanisms to record audio for individual slides and combine them into a consecutive recording. This allows presentations to be played independently with synchronized narration.

## Recording Audio and Autoplay Configuration

To record audio and configure autoplay, follow these steps:

1. Open the PowerPoint presentation.
2. Navigate to the "Slide Show" tab.
3. Select "Record Slide Show" to begin capturing narration for each slide.
4. Ensure the timing is set to advance slides automatically based on the recorded audio duration.
5. Save the file in a format that preserves timings and audio (e.g., .pptx).

## Self-Evaluation

??? note "How do you ensure that audio transitions are seamless between slides?"
    By using the "Record Slide Show" feature, PowerPoint automatically handles the timing and sequencing of audio clips across consecutive slides.

??? note "Which tab in PowerPoint is used to access recording features?"
    The "Slide Show" tab contains the options for recording the slide show and managing timings.
