## Overview

The creation of a functional Large Language Model (LLM) is not a single training event but a multi-stage pipeline. This process transforms a raw neural network into a helpful, safe, and steerable assistant. The lifecycle generally follows three primary stages: Pre-training, Supervised Fine-Tuning (SFT), and Alignment.

The progression can be summarized as:
Base Model (World Knowledge) $\rightarrow$ Instruct Model (Task Following) $\rightarrow$ Aligned Model (Safety and Preferences).

## Core Sections

### Pre-training

Pre-training is the most computationally expensive phase of the LLM lifecycle. The goal is to create a "Base Model" that understands the statistical structure of language and possesses broad general knowledge.

Why this matters: Pre-training is where the model acquires its "intelligence" and world knowledge. Without a robust pre-training phase, subsequent tuning cannot add capabilities; it can only unlock or refine existing ones.

1. Next-Token Prediction
The core objective is self-supervised learning. Given a sequence of tokens, the model predicts the probability distribution of the next token. This is achieved using a causal language modeling objective, where the model is prevented from "looking ahead" at future tokens in the sequence.

2. Data Corpora
Models are trained on massive datasets such as Common Crawl (web scrapings), The Pile, and specialized repositories of code (GitHub) and academic papers (arXiv). Data quality is prioritized over raw quantity to prevent the model from learning noise or systemic biases.

3. Scaling Laws
Scaling laws describe the empirical relationship between model performance and three variables: compute (FLOPs), dataset size (tokens), and model size (parameters).

:::tip Best Practice
Follow the Chinchilla scaling laws: for a given compute budget, the model size and training data should be scaled in equal proportions to achieve optimal performance.

:::warning Pitfall
Over-training a small model on too much data (or under-training a large model) leads to suboptimal efficiency. The compute-optimal point is critical for reducing inference costs later in the lifecycle.

### Supervised Fine-Tuning (SFT)

A base model is a document completer, not an assistant. If asked "What is the capital of France?", a base model might respond with "What is the capital of Germany?" because it perceives the input as a list of questions. SFT transforms this behavior.

Why this matters: SFT teaches the model the "format" of a conversation and the concept of following instructions. This process is known as Instruction Tuning.

1. Instruction Datasets
SFT uses a curated dataset of (Prompt, Response) pairs. These pairs are often written by humans or generated by more capable models (distillation).

2. The SFT Process
The model is trained using the same next-token prediction objective but only on the response portion of the pair. The prompt is treated as context and does not contribute to the loss calculation.

Below is a simplified implementation of an SFT loss function in PyTorch.

```python
import torch
import torch.nn.functional as F

def sft_loss(logits, labels):
    """
    Simplified SFT loss: Cross-Entropy loss on the shifted next-token prediction.
    
    Args:
        logits: Model output tensor of shape (batch_size, seq_len, vocab_size)
        labels: Target token IDs of shape (batch_size, seq_len)
    """
    # Shift so that tokens < n predict n
    shift_logits = logits[..., :-1, :].contiguous()
    shift_labels = labels[..., 1:].contiguous()
    
    # Flatten the tokens for cross-entropy calculation
    flattened_logits = shift_logits.view(-1, shift_logits.size(-1))
    flattened_labels = shift_labels.view(-1)
    
    # Standard cross entropy loss for next-token prediction
    loss = F.cross_entropy(flattened_logits, flattened_labels)
    return loss
```

### Alignment (RLHF & DPO)

Alignment ensures the model is helpful, honest, and harmless. While SFT teaches the model how to respond, alignment teaches it *which* response is better.

Why this matters: SFT can lead to "hallucinations" where the model confidently provides wrong answers because it is simply trying to mimic the training data. Alignment penalizes these behaviors.

1. Reinforcement Learning from Human Feedback (RLHF)
RLHF typically involves three steps:
1. SFT: Create a baseline instruct model.
2. Reward Modeling: Train a separate, smaller model to predict which of two responses a human would prefer.
3. Optimization: Use Proximal Policy Optimization (PPO) to update the LLM's weights to maximize the reward model's score.

2. Direct Preference Optimization (DPO)
DPO removes the need for a separate reward model. It optimizes the LLM directly on preference pairs (Chosen, Rejected) using a modified loss function that implicitly defines the reward.

:::tip Best Practice
Use DPO for faster iteration and lower stability risks compared to PPO, as it avoids the complexities of managing multiple models (Actor, Critic, Reference) in memory.

3. Constitutional AI
To scale oversight, Constitutional AI uses a "constitution" (a set of written principles). A model is used to critique its own responses based on these principles and then retrains itself to follow the critiques, reducing the reliance on manual human labeling.

## Assignments

!!! note "Assignment 1: Pre-training Dynamics"
    Explain why the "next-token prediction" objective is sufficient for a model to learn complex logic and world facts.
    ??? question "Solution"
        By predicting the next token across billions of diverse contexts, the model must internally represent the underlying structures (grammar, logic, factual relationships) that make those predictions accurate. For example, to predict the word "Paris" after "The capital of France is", the model must store the fact that Paris is the capital of France.

!!! note "Assignment 2: SFT vs. Alignment"
    A model has been SFT-tuned on a dataset of medical textbooks but still provides dangerous medical advice. Which stage of the lifecycle failed, and how would you fix it?
    ??? question "Solution"
        The Alignment stage failed. SFT teaches the model to look like a medical textbook (which contains facts), but it does not teach the model to refuse dangerous requests or prioritize safety. The fix is to implement RLHF or DPO using preference pairs where dangerous advice is labeled as "Rejected" and cautious, safe advice is labeled as "Chosen".
