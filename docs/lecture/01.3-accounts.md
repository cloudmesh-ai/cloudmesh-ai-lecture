# Setting Up Your Accounts

To participate in the hands-on portions of this course, you will need accounts for several cloud and infrastructure services. Please set these up as early as possible to avoid delays in your projects.

## 1. Local Development First

!!! important 
    Before deploying any resources to the cloud, it is strongly recommended that you develop and test your scripts, containers, and configurations on your own local computer.

Cloud resources, even within "free tiers," can incur costs if misconfigured or if you exceed the free limits. Testing locally (using tools like Docker or local virtual machines) ensures that your code is working correctly before you move it to a production or cloud environment where costs might be associated.

---

## 2. Chameleon Cloud

Chameleon is a testbed for cloud computing research and education. It provides a powerful environment for deploying virtual machines and managing infrastructure.

*   **Registration**: Registration for Chameleon usually requires institutional approval. Please check the instructions provided on Sakai for the specific registration link and the "Project" name you should request to join.
*   **What to expect**: Once approved, you will have access to a dashboard where you can create images, launch instances, and manage networks.

## 3. Access-CI

Access-CI provides specialized compute resources for research and education.

*   **Registration**: Similar to Chameleon, Access-CI accounts are often linked to institutional identity. Follow the guidelines posted in the course materials to request an account.
*   **Usage**: These resources are typically used for more computationally intensive tasks that exceed the capabilities of standard free cloud tiers.

## 4. Public Cloud Free Tiers

Most major cloud providers offer a "Free Tier" for new users. These are excellent for learning the basics of industry-standard cloud services.

### Amazon Web Services (AWS)
*   **Free Tier**: AWS offers a "Free Tier" which includes 12 months of limited usage for certain services (like EC2 t2.micro/t3.micro instances) and "Always Free" services.
*   **Setup**: Create an account at [aws.amazon.com](https://aws.amazon.com/). You will need a credit card for verification, although you will not be charged if you stay within the free limits.

### Microsoft Azure
*   **Free Tier**: Azure provides a set of popular free services and a credit (usually $200) for the first 30 days.
*   **Setup**: Create an account at [azure.microsoft.com](https://azure.microsoft.com/). A university email address often provides additional student credits without requiring a credit card.

### Google Cloud Platform (GCP)
*   **Free Tier**: GCP offers a "Free Trial" credit (typically $300) and a "Free Tier" for specific low-cost services.
*   **Setup**: Create an account at [cloud.google.com](https://cloud.google.com/).
