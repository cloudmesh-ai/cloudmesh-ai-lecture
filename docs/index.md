# Cloud Computing, DevOps, and AI


## Course Overview

This is a hands-on, project-based course that introduces students to modern cloud infrastructure, DevOps practices, and the integration of AI into cloud-native applications. 

### Key Focus Areas:

* **Cloud Infrastructure**: Practical experience with AWS and other public cloud providers.
* **DevOps Practices**: Containerization (Kubernetes), automation tools (Ansible, Jenkins), and Python scripting.
* **AI Integration**: Exploring the use of AI services and the deployment of LLMs in the cloud.

### Web Page and Course Material

The course material will be presented in Lectures. However we have sections that can be used as additional resource. In some cases we point out explicitly to these resources. 

### Learning Outcome

The course emphasizes learning by doing, encouraging creativity and independent exploration. Each student designs and implements an original project tailored to their interests, applying course concepts to solve real-world problems.
