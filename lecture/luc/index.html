    Lecture Notes: Cloud Computing, DevOps, and AI¶

    This document provides the comprehensive syllabus for the Cloud Computing, DevOps, and AI course, outlining learning outcomes, meeting times, and the tentative schedule. It details the required materials, grading policy, and expectations for student projects and class participation.

    • Gregor von Laszewski
    • Fall 2026, COMP 388-003 (4613)
    • Fall 2026, COMP 488-003 (4612)

    Legend: 🔴 Will be presented, ⚪ Not yet presnted, 🔵 presentation under construction

    Content

    Chapter 1: Class Organization¶

    Welcome to the Class Organization section of the course. This chapter serves as the central administrative hub for the course. It provides students with the essential framework for navigating the lectures, including the course syllabus, contribution guidelines, and supplemental resources.

    Here, you will find the overarching schedule, communication channels for community Q&A, and a comprehensive overview of the assignments and projects required for the course. This hub is designed to ensure all participants have clear visibility into course expectations, deadlines, and the available support materials.

    • Part I: Syllabus and Lectures

      • 🟢 Syllabus: Course goals, schedule, and expectations.
      • 🟢 Temporary Schedule breakdown of the course timeline.
      • 🟢 TOC Schedule list of the TOC of the Web site and the dates a presentation was given.
      • 🟢 Contributing: How to help improve and expand these lecture notes.
      • 🟢 Supplemental Materials: Additional resources to support your learning.
      • 🟢 Piazza: Course communication and community Q&A.

    • Part II: Assignments and Projects

      • 🟢 Assignments Overview: A high-level guide to the course assignments.
      • 🟢 Assignments List: Detailed requirements and instructions for all course tasks.

      • 🟢 Project Report Format: Detailed requirements and instructions for all course tasks.

        • 🟢 Markdown Format: Markdown syntax
        • ⚪ ACM Markdown: ACM styling for research papers.

        • ⚪ ACM LaTeX with Overleaf: ACM styling for research papers in overleaf.

        • Diagrams: 🟢 Mermaid Diagrams, 🟢 Graphviz Diagrams

    • Part III: Media and Resources

      • 🟢 Lecture Videos: Links to recorded sessions and video presentations.

    Chapter 2: Accounts¶

    Welcome to the Accounts section of the course. This chapter focuses on managing access and credentials across different cloud providers and local environments to ensure secure and efficient resource utilization.

    • Part I: Cloud Provider Accounts

      • ⚪ Amazon Web Services (AWS): Setting up and managing AWS accounts and credentials.
      • ⚪ Microsoft Azure: Azure account management and resource organization.
      • ⚪ Google Cloud Platform (GCP): Google Cloud projects and Identity and Access Management (IAM).
      • 🟢 Chameleon Cloud: Accessing and managing resources on the Chameleon research cloud.
      • 🟢 Local Accounts: Managing local credentials and virtualized environment access.

    • Part II: Access CI

      • 🟢 Access CI: Automating account access and credential management within CI/CD pipelines.

    Chapter 3: Cloud Computing Fundamentals¶

    Welcome to the Cloud Computing Fundamentals section of the course. This chapter provides a foundational understanding of the technologies and principles that enable modern cloud computing, focusing on the critical shift from static, physical hardware to dynamic, virtualized environments.

    • Part I: Introduction to the Cloud

      • 🟢 Introduction: An overview of cloud computing fundamentals and the transition from legacy infrastructure.

    • Part II: Virtualization Mechanics

      • 🟢 Virtualization Core: A deep dive into the virtualization engine that powers the cloud.
      • 🟢 The Virtualization Landscape: Exploration of the various hypervisors and platforms available in the ecosystem.
      • 🟢 Virtual Machine Technologies: A technical look at the different VM implementations and their architectural trade-offs.
      • 🔴 Adoption & Popularity: Analysis of the trends and drivers behind the widespread use of virtualization.

    Chapter 4: Local Virtual Machine Implementation and Platforms¶

    🟢 Welcome to the Virtual Machine Implementation and Platforms section of the course. This chapter moves from the theoretical foundations of virtualization to the practical implementation, exploring the architecture of VM hosts and the various platforms used to deploy and manage virtual instances, from local development environments to large-scale research clouds.

    • Part I: VM Implementation and Platforms
      • Local Virtualization Platforms:
        • Rapid Deployment: 🟢 Multipass for Ubuntu instances, 🟢 Vagrant for reproducible environments, and 🟢 Lima for macOS Linux VMs.
        • Virtual Box: 🟢 Using VirtualBox for local virtualization.
        • Windows Linux Integration:
          • 🟢 Working with WSL2
          • 🟢 Configuring SSH access for WSL2
          • 🟢 Managing SSH keys for WSL2
        • Low-Level Tooling: 🟢 QEMU basics, 🟢 managing VMs with virsh, and 🟢 using UTM on Apple Silicon.
        • The State of Virtual Machine Frameworks: 🟢 Different VM Framework list.
        • VMs using Architectures:
          • Architecture on macOS: 🟢 Detailed architectural patterns for VM management on macOS.
          • Architecture on Windows: 🟢 Detailed architectural patterns for VM management on Windows.

    Chapter 5: Openstack Virtual Machine Implementation and Platforms¶

    Welcome to the OpenStack and Research Cloud Platforms section of the course. This chapter focuses on the implementation and management of private clouds using OpenStack, exploring how this powerful IaaS platform is utilized by research clouds like Chameleon and Jetstream to provide scalable compute, networking, and storage resources.

    • Part I: Introduction to OpenStack

      • Fundamentals: 🟢 Introduction to OpenStack: IaaS for the Enterprise: A comprehensive overview of OpenStack's role, its core services (Nova, Neutron, Cinder, etc.), and its importance for AI workloads.
      • Control Plane: 🟢 Managing the Cloud: The OpenStack Horizon Dashboard: A guide to navigating the web-based GUI and managing cloud resources visually.
      • Optimization: 🟢 Strategies for reducing OpenStack costs.

    • Part II: OpenStack Research Cloud Platforms

      • Chameleon Cloud:
        • Environment: 🟢 Introduction to the Chameleon environment.
        • Provisioning: 🟢 Managing reservations and using the 🟢 Horizon dashboard.
        • Operations: 🟢 OS command-line management and 🟢 OS-level Python automation.
        • Integration: 🟢 Using the Python CHI library.
        • Economics: 🟢 Understanding and managing costs on Chameleon.
      • Jetstream:
        • VM Basics: 🟢 Deploying and managing VMs on Jetstream.
        • Scaling: 🟢 Multi-node deployments, including 🔵 Visualizing multi-node deployments and 🔴 Orchestration with Heat.
        • Administration: 🟢 Jetstream cost management and 🟢 Documentation via mkdocs.

    • Part III: Openstack CLI

      • 🟢 OpenStack command-line management: A step-by-step guide for provisioning and managing VMs using the openstack CLI.

    • Part IV: Openstack programming

      • 🟢 Python automation with OpenStack SDK: Tutorial on using openstacksdk for programmatic VM creation and management.
      • 🟢 High-level automation with python-chi: Simplified OpenStack resource management for Chameleon Cloud.
      • 🟢 Multi-cloud abstraction with Libcloud: Using Apache Libcloud for vendor-neutral cloud management.

    • Part V: Openstack Automation

      • 🔴 Introduction to OpenStack Heat: Understanding the concept of orchestration, Heat templates (HOT), and the lifecycle of a stack.
      • 🔴 Advanced API Integration: Implementing FastAPI wrappers to simplify Heat operations.
      • 🔴 Project-Wide Access: Configuring and managing Heat API access across different project scopes.
      • 🔴 Jetstream Multi-Node Orchestration: Using Heat templates to deploy complex, multi-node clusters on the Jetstream platform.

    • Part VI: OpenStack Storage

      • Overview: 🔴 Overview of Storage Services in Openstack.
      • Block Storage (Cinder): 🔴 Management of persistent block devices and volume attachment.
      • Object Storage (Swift): 🔴 Scalable, S3-compatible storage for unstructured data.
      • Image Registry (Glance): 🔴 Storage and retrieval of VM snapshots and base images.

    • Part VII: Openstack Development and Testing

      • Development: 🔴 Getting started with DevStack for local OpenStack development.

    • Part VIII: Application Development

      • API Integration: 🔴 Building FastAPI wrappers for Heat and 🔴 managing project-wide access.

    Chapter 6: Public Clouds Virtual Machine Implementation and Platforms¶

    This chapter provides a comprehensive guide to provisioning and managing virtual machines across the major public cloud providers, focusing on accessibility, cost-efficiency, and automation.

    Part I: Foundations and Cost Analysis¶

    • 🔵 Understanding Cloud Free Tiers: Navigating promotional credits and "Always-Free" offerings to start learning without cost.
    • 🔵 Pay-as-you-go Cost Comparison: A detailed price analysis for small Linux VMs across AWS, Azure, GCP, and Oracle.
    • 🔵 Spot Pricing Guide: Understanding pre-emptible and spot instances to reduce compute costs by up to 80%.
    • 🔵 Launching Spot Instances: Practical implementation of spot instances using CLI, Libcloud, and Native SDKs.

    Part II: Cloud-Specific Implementation¶

    Amazon Web Services (AWS)¶

    • 🔵 AWS CLI Free-Tier Tutorial: Step-by-step guide from account creation to a running EC2 instance.
    • 🔵 AWS Native Python SDK (boto3): Automating EC2 provisioning and cleanup using the official AWS SDK.

    Microsoft Azure¶

    • 🔵 Azure CLI Free-Tier Tutorial: Guide to setting up a B1s Linux VM within the Azure free tier.
    • 🔵 Azure Native Python SDK: Programmatic VM management using azure-mgmt-compute and azure-identity.

    Google Cloud Platform (GCP)¶

    • 🔵 GCP SDK Free-Tier Tutorial: Provisioning an e2-micro instance using the gcloud tool.
    • 🔵 GCP Native Python SDK: Using google-cloud-compute for automated VM lifecycle management.

    Oracle Cloud Infrastructure (OCI)¶

    • 🔵 Oracle Cloud Free-Tier Tutorial: Leveraging the generous "Always-Free" ARM and AMD shapes.
    • 🔵 Oracle Native Python SDK: Automating OCI compute instances using the oci Python library.

    Part III: Multi-Cloud Automation¶

    • 🔵 Managing VMs with Apache Libcloud: Using a single Python API to manage VMs across multiple providers and avoid vendor lock-in.
    • 🔵 Summary and Provider Comparison: A final synthesis comparing the ease of use, reliability, and performance of the providers.

    Chapter 7: DevOps¶

    This chapter explores how to bridge the gap between software development and IT operations to deliver high-quality software reliably and consistently.

    Part I: Foundations of DevOps¶

    • 🔴 Introduction to DevOps: The core philosophy, the DevOps lifecycle, and the importance of feedback loops.
    • 🔴 DevOps and Organizational Culture: Conway's Law, Team Topologies, and Collaborative Engineering.

    Part II: Infrastructure as Code (IaC)¶

    • 🔴 The Core of IaC: Declarative vs. Procedural approaches and the concept of idempotence.
    • 🔴 Server Provisioning with Terraform: Managing cloud resources with HCL and state files.
    • 🔴 Configuration Management with Ansible: Agentless automation and playbook-driven configuration.
    • 🔴 Enterprise Scale with Puppet: The pull-based model and state enforcement at scale.
    • 🔴 Dynamic Configuration with Jinja2: Using templates to make infrastructure DRY and dynamic.

    Part III: Continuous Integration and Delivery (CI/CD)¶

    • 🔴 The CI/CD/CM Framework: Understanding the integrated pipeline from Continuous Development to Continuous Improvement.

    From Local Automation to Global Orchestration¶

    • 🟢 Task Automation with Make: Using Makefiles as the "glue" for local automation, providing a consistent interface before moving to the cloud.
    • 🔴 CI/CD Tooling Landscape: A comparative look at modern orchestrators that scale local automation to the entire organization.
      • 🔴 GitHub Actions: Event-driven automation integrated into source control.
      • 🔴 Jenkins: The universal, extensible automation orchestrator.
      • 🔴 CircleCI: Managed, container-first CI/CD.
      • 🔴 Travis CI: Configuration-as-code for open source.

    Part IV: Cloud-Native Implementation & Observability¶

    • 🔵 GitOps Fundamentals: The "single source of truth" model and pull-based synchronization.
    • 🔵 ArgoCD: Implementing declarative continuous delivery for Kubernetes clusters.
    • 🔵 DevOps on AWS: Leveraging the AWS CodeSuite for a unified toolchain.
    • 🔵 Observability with Azure Monitor: Moving from reactive monitoring to proactive observability.

    Part V: DevSecOps and Hardening¶

    • 🔵 DevSecOps Fundamentals: Policy as Code, secrets management, and the shift-left philosophy.
    • 🔵 Securing the Pipeline: Implementation details for GitHub Actions and supply chain security.

    Part VI: AI and the Future of DevOps¶

    • 🔵 AI-Augmented DevOps: From "Syntax Writer" to "Architectural Reviewer"—leveraging LLMs for IaC, AIOps, and automated pipelines.

    Practical Application¶

    • 🔵 Example DevOps Project: A comprehensive capstone project showing the integration of various DevOps tools from provisioning to monitoring.
    • 🔵 Local Lab Guide: Instructions for students wanting to try these tools locally.
