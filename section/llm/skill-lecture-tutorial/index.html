    A “Lecture‑Builder” Skill for Cline

    Below is a ready‑to‑use skill that lets you turn a simple specification (topic, audience, length, depth) into a full‑fledged lecture / tutorial outline – complete with slide titles, key points, code snippets, and optional “quick‑quiz” questions.

    You can drop this skill into your skills/ folder, register it in cline.yaml, and then call it from the terminal:

    cline lecture_builder --topic "Introduction to Python for Data Science" \
                      --audience "undergraduate beginners" \
                      --duration 90 \
                      --depth "hands‑on"

    The skill returns JSON that you can pipe to jq, feed into a markdown‑to‑slide converter, or simply paste into your teaching material.

    1️⃣ Skill implementation (Python)

    Make it executable: chmod +x skills/lecture_builder.py

    A “Lecture‑Builder” Skill for Cline

    Below is a complete, ready‑to‑use skill that turns a simple specification (topic, audience, length, depth) into a structured lecture / tutorial outline.
    The output is JSON, so you can pipe it to jq, feed it into a markdown‑to‑slide converter, or paste it directly into your teaching material.

    1️⃣ What the skill does

    Input you give the skill What the skill returns
    --topic "Introduction to Python for Data Science"
    --audience "undergraduate beginners"
    --duration 90
    --depth hands‑on    		 A JSON object containing:
    • estimated number of slides
    • intro slide title
    • agenda slide
    • section titles, bullet points, and (optional) code snippets
    • a short “quick‑quiz” (only for hands‑on depth)
    You can also use the skill for a quick “overview” or a “deep‑dive” – just change --depth.

    Because the skill returns pure JSON, you can combine it with any downstream tool (e.g., pandoc, reveal.js, marp, or a custom slide generator).

    my‑cline‑project/

    That’s it – Cline will automatically expose the command lecture_builder.

    🎓 “Lecture‑Builder” Skill – Turn a Simple Prompt into a Full‑Featured Lecture/Tutorial Outline

    Below is a complete, ready‑to‑use skill that you can drop into a Cline project.
    It accepts a few command‑line arguments (topic, audience, duration, depth) and returns a JSON outline that you can feed directly into markdown‑to‑slide tools, a static‑site generator, or simply copy‑paste into your teaching material.

    1️⃣ What the skill does

    Input you give the skill What you get back
    --topic "Intro to Python for Data Science"
    --audience "undergrad beginners"
    --duration 90
    --depth hands‑on    		 JSON containing:
    • estimated number of slides
    • intro‑slide title
    • agenda slide
    • section titles + bullet points
    • optional code snippets for demo sections
    • a short “quick‑quiz” (only for hands‑on depth)
    You can also use --depth overview or --depth deep‑dive – the skill only changes the amount of interactivity (quiz vs. none).

    Because the output is pure JSON, you can pipe it to jq, transform it to markdown, or feed it into any slide generator you like.

    2️⃣ Where to put the skill

    my‑cline‑project/
│
├─ cline.yaml                # (optional) central skill registry
│
├─ skills/                   # <‑‑ place the file here
│   └─ lecture_builder.py
│
└─ README.md
    1. Create the folder skills/ (or any folder you expose via the CLINE_SKILLS_PATH environment variable).
    2. Save the file lecture_builder.py inside that folder.
    3. Make it executable 
    chmod +x skills/lecture_builder.py

    Cline will automatically expose a command called lecture_builder that you can invoke from the shell.

    3️⃣ The skill code (copy‑paste it into skills/lecture_builder.py)

    Why it works everywhere: The script uses only the Python standard library, so no extra packages are required.
    If you want richer, AI‑generated content, replace the generate_outline function with a call to an LLM (OpenAI, Anthropic, etc.). The rest of the contract (JSON output, exit‑code handling) stays the same.

    #!/usr/bin/env python3
import sys, json, argparse
from datetime import datetime

def generate_outline(topic, audience, duration, depth):
    """
    Very simple template‑driven outline generator.
    Replace this with an LLM call for more sophisticated output.
    """
    # Rough estimate: ~1 slide per 10 minutes (minimum 5 slides)
    slides_est = max(5, duration // 10)

    intro = f"Welcome & Motivation – Why {topic} matters for {audience}"
    agenda = "Agenda\n1. Context & Goals\n2. Core Concepts\n3. Hands‑on Demo\n4. Common Pitfalls\n5. Q&A / Wrap‑up"

    sections = [
        {
            "title": "Context & Goals",
            "points": [
                f"Define {topic}",
                "Real‑world use‑cases",
                "Learning objectives"
            ]
        },
        {
            "title": "Core Concepts",
            "points": [
                "Fundamental ideas",
                "Key terminology",
                "Simple examples"
            ]
        },
        {
            "title": "Hands‑on Demo",
            "points": [
                "Step‑by‑step code walkthrough",
                "Live execution (Jupyter / REPL)",
                "Student exercise"
            ],
            "code_snippet": "# Example placeholder\nprint('Hello, data science!')"
        },
        {
            "title": "Common Pitfalls",
            "points": [
                "Typical mistakes",
                "Debugging tips",
                "Best‑practice checklist"
            ]
        },
        {
            "title": "Q&A / Wrap‑up",
            "points": [
                "Recap of key take‑aways",
                "Further reading",
                "Assignment / next steps"
            ]
        }
    ]

    # Optional quick‑quiz for hands‑on sessions
    quiz = []
    if depth.lower() == "hands‑on":
        quiz = [
            {
                "question": f"What is the first line you would write to import {topic.split()[0]}?",
                "answer": "import pandas as pd" if "pandas" in topic.lower() else "import numpy as np"
            },
            {
                "question": "Name one common pitfall when starting with this topic.",
                "answer": "Skipping data cleaning"
            }
        ]

    outline = {
        "generated_at": datetime.utcnow().isoformat() + "Z",
        "topic": topic,
        "audience": audience,
        "duration_minutes": duration,
        "estimated_slides": slides_est,
        "intro_slide": intro,
        "agenda_slide": agenda,
        "sections": sections,
        "quiz": quiz
    }
    return outline

def main():
    parser = argparse.ArgumentParser(
        description="Generate a lecture / tutorial outline (JSON) for Cline")
    parser.add_argument("--topic", required=True, help="Lecture / tutorial topic")
    parser.add_argument("--audience", required=True, help="Target audience description")
    parser.add_argument("--duration", type=int, default=60,
                        help="Length in minutes (default: 60)")
    parser.add_argument("--depth", choices=["overview", "hands‑on", "deep‑dive"],
                        default="overview", help="Level of interactivity")
    args = parser.parse_args()

    outline = generate_outline(args.topic, args.audience,
                               args.duration, args.depth)

    # Emit clean JSON to stdout – Cline expects this format
    print(json.dumps(outline, indent=2, ensure_ascii=False))

if __name__ == "__main__":
    main()

    4️⃣ Optional registry entry (cline.yaml)

    If you want richer help text or explicit argument definitions, add a block like this to the project‑root cline.yaml:

    skills:
  lecture_builder:
    command: "./skills/lecture_builder.py"
    description: "Generate a structured lecture / tutorial outline (JSON) from a short spec."
    args:
      - name: topic
        type: string
        required: true
        help: "Lecture or tutorial topic"
      - name: audience
        type: string
        required: true
        help: "Who will attend (e.g., 'undergrad beginners')"
      - name: duration
        type: int
        required: false
        default: 60
        help: "Length in minutes"
      - name: depth
        type: string
        required: false
        choices: ["overview", "hands‑on", "deep‑dive"]
        default: "overview"
        help: "Level of interactivity"

    Now cline lecture_builder --help will show a nicely formatted help page.

    • Pipe to jq for quick inspection: cline lecture_builder … | jq '.sections[].title'
    • Convert to markdown (a tiny helper script can turn each section into a ## heading with bullet points).

    6️⃣ Extending the skill (ideas)

    Idea How to implement
    AI‑generated content Replace generate_outline with a call to an LLM (e.g., openai.ChatCompletion.create) and feed the same prompt. Keep the JSON formatting logic the same.
    Dynamic slide count Use token‑counting (via litellm or tiktoken) on the generated text to better estimate slide length.
    Image suggestions Add a field "image_url" per section that points to royalty‑free images from Unsplash or Pixabay (you can call their APIs).
    Export to multiple formats Add a --format markdown|json|pdf flag; for PDF you could call pandoc under the hood.
    User‑provided template Accept a path to a Jinja2 template and render the JSON into whatever document style you prefer.
    Collaborative mode Store the generated JSON in a shared DB (e.g., Firebase, Supabase) and expose a small web UI for collaborators to edit sections.

    7️⃣ Quick checklist to get the skill running

    1. mkdir -p my‑cline‑project/skills
    2. Save the Python script above as my‑cline‑project/skills/lecture_builder.py
    3. chmod +x my‑cline‑project/skills/lecture_builder.py
    4. (optional) Create my‑cline‑project/cline.yaml with the registry entry shown in §4.
    5. From the project root run a test call:
    cline lecture_builder --topic "Intro to Git & GitHub" --audience "new developers" --duration 45 --depth overview

    You should see a nicely‑formatted JSON outline printed to the console.

    ✅ TL;DR

    • Skill name: lecture_builder
    • Purpose: Turn a one‑line spec into a complete lecture outline (JSON).
    • Where to put it: skills/lecture_builder.py (make it executable).
    • How to register: optional entry in cline.yaml; otherwise the file name becomes the command automatically.
    • How to run: cline lecture_builder --topic "...“ --audience "...“ --duration <minutes> --depth <overview|hands‑on|deep‑dive>
    • What you get: JSON with intro, agenda, section titles, bullet points, optional code snippets, and a short quiz.

    With this skill you can spin up lecture or tutorial scaffolding in seconds, keep the process vendor‑agnostic, and stay fully inside the Cline ecosystem. Happy teaching!
